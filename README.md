# CFPS 2022 农村上网居民网络购物采纳影响因素分析

这是一个使用 CFPS 2022 家庭经济库与成人库完成的实证数据分析项目，覆盖：

> 数据读取 → 缺失编码处理 → 家庭—成人匹配 → 样本构建 → 描述统计 → Probit / Logit / LPM → 平均边际效应 → 分组比较 → 校准与可视化 → 自动报告

## 1. 为什么改题

原版项目把家庭经济库字段 `ft601` 当作“数字服务采纳”。核对 CFPS 2022 变量标签后确认：

- `ft601` = **亲友借款待偿额（元）**
- 它与互联网、数字服务无关
- 全样本 10,726 户中，`ft601` 有 9,640 户为 `-8`（不适用），仅 992 户大于 0

因此原版被解释变量不成立。新版改用成人库 `qu92`“是否网上购物”作为数字服务使用的结果变量，并把样本限定为 **农村、且使用移动互联网的成年受访者**。这也意味着研究问题从“数字服务采纳”收窄为“农村上网居民的网络购物采纳”。

## 2. 数据与合规

需要两份 CFPS 2022 原始数据：

- `cfps2022famecon_202410.dta`：家庭经济库
- `cfps2022person_202410.dta`：成人库

原始数据和行级衍生数据受 CFPS 使用协议保护，**不随项目提供、不提交到 Git、不对外分享**。本仓库只保留代码与汇总结果（系数、边际效应、分组率、图表）。

## 3. 快速运行

```bash
pip install -r requirements.txt

python analysis.py \
  --fam "D:/path/cfps2022famecon_202410.dta" \
  --adult "D:/path/cfps2022person_202410.dta" \
  --out output/real
```

测试环境：Python 3.10、pandas 2.3、statsmodels 0.14、matplotlib 3.10。

## 4. 核心口径

| 项目 | 口径 |
|---|---|
| 研究人群 | 农村（`urban22 = 0`）且移动上网（`qu201 = 1`）的成年受访者 |
| 结果变量 | `qu92` 是否网上购物，1 = 是，0 = 否 |
| 核心解释变量 | 年龄、年龄平方、男性、受教育年限、家庭人口规模、人均收入对数、土地资产对数、电脑上网 |
| 样本量 | 2,344 |
| 结果变量均值 | 52.65% |
| 估计方法 | Probit 为主；Logit、LPM 稳健性参考 |
| 标准误 | HC1 异方差稳健标准误 |
| 缺失处理 | CFPS 负值特殊编码统一设为缺失，完整案例回归 |
| 权重 | 未使用 CFPS 调查权重（局限） |

### 为什么限定“移动上网者”

`qu92` 只对上网者提问。未上网者的 `qu92` 多为 `-8`（不适用），如果直接编码为 0，会把“没有上网”与“上网但不网购”混为一谈。新版把“是否上网”作为样本准入条件，而不是解释变量，避免这种口径错误。

## 5. 主要结果

- 2,344 名农村移动上网者中，**52.65%** 使用过网络购物。
- 年龄呈显著倒 U 型，预测概率在 **34.6 岁**左右达到峰值；30 岁约 62.7%，60 岁约 37.3%。
- 控制其他变量后：
  - 男性比女性低 **11.6 个百分点**；
  - 受教育年限每增加 1 年，概率提高 **1.17 个百分点**；
  - 人均收入每提高 10%，概率提高约 **0.34 个百分点**；
  - 同时使用电脑上网者，概率高 **13.0 个百分点**；
  - 家庭人口规模、土地资产不显著。
- 模型拟合：Pseudo R² = **0.111**，AUC = **0.720**。

> 以上为条件相关关系，不是因果效应；未使用调查权重，不能直接外推到全国农村人口。

## 7. 方法说明

1. **变量编码**：`urban22` 的 0 = 乡村，1 = 城镇；`gender` 的 1 = 男，0 = 女；`qu201`、`qu202`、`qu92` 的 1 = 是，0 = 否。
2. **收入与资产**：使用 `log(1+x)`，避免零值与右偏分布的影响。
3. **年龄非线性**：同时纳入年龄与年龄平方，报告峰值年龄与预测概率曲线，不单独解释平方项系数。
4. **边际效应**：Probit/Logit 的原始系数不是概率变化，因此报告平均边际效应（AME）。
5. **不确定性**：分组率使用 Wilson 置信区间；模型使用 HC1 稳健标准误。
6. **模型评价**：使用 Pseudo R²、AIC/BIC、AUC、Brier score 与十分位校准，而不是只看显著性。

## 8. 局限

- 横截面数据，不能识别因果方向；电脑上网、收入可能与不可观测的数字能力、社会资本相关。
- 样本限定为农村移动上网者，结论不能推广到未上网农村居民。
- 未使用 CFPS 抽样权重，估计不代表全国代表性水平。
- 网络购物只是数字服务的一个切面，不能代表在线教育、在线医疗、数字金融等全部数字服务。
- 完整案例回归可能引入选择性；后续可做多重插补与权重稳健性检验。
